## **📜 Ezee-Blitz - E-Commerce Website**  

### **🌐 Overview**  
Ezee-Blitz is a **modern and responsive e-commerce platform** built using ReactJS and AJAX. It offers a seamless shopping experience with real-time updates, dynamic product listings, and efficient state management using React Toolkit.

## **🚀 Key Features**  

✅ **Fully Responsive UI** – Adapts to desktops, tablets, and mobile devices  
✅ **Dynamic Content Loading** – AJAX-based API integration for real-time updates  
✅ **Optimized Performance** – React Toolkit for efficient state management  
✅ **User-friendly Navigation** – Smooth and intuitive shopping experience  
✅ **Fast & Scalable** – Designed for speed and security  

---

## **🛠️ Tech Stack**  

| Technology  | Description  |
|-------------|-------------|
| **Frontend**  | HTML, CSS, Bootstrap, ReactJS  |
| **State Management** | React Toolkit |
| **Data Handling** | AJAX, JSON |
| **API Integration** | Dynamic product loading using AJAX |

## **📥 Installation & Setup**  

### **1️⃣ Clone the Repository**  
git clone https://github.com/Rajendra93971/Ezee-blitz.git
cd Ezee-blitz

### **2️⃣ Install Dependencies**  
npm install

### **3️⃣ Start the Development Server**  
npm run dev
Runs the app at **http://localhost:5173/**


## **📌 Folder Structure**  

Ezee-Blitz/
│── public/            # Static assets  
│── src/               # Source code  
│   ├── components/    # Reusable UI components  
│   ├── features/      # Redux slices  
│   ├── pages/         # Main pages (Home, Cart, Single Product)  
│   ├── data.js        # Product data (JSON)  
│── package.json       # Project dependencies  
│── vite.config.js     # Vite configuration  
│── README.md          # Documentation  


## **📦 Deployment**  
For production, build the app using:  
npm run build

Deploy on **Vercel / Netlify**.
